# Regla sobre Preguntas al Usuario

Cuando hagas preguntas al usuario (especialmente durante sesiones de "grilling" como `/grill-me-rg` o `/grill-with-docs`), **NO generes alternativas de respuesta utilizando modales o botones interactivos** (no uses la herramienta `ask_question` para opciones cerradas).

Debes plantear la pregunta directamente como texto plano en el chat, listando las alternativas y tu recomendación. Esto es para permitir que el usuario pueda responder libremente usando la caja de texto abierta, y tenga la opción de adjuntar documentos, archivos, o llamar a otros comandos slash (skills) en su respuesta.
