# Glosario de dominio — Agile Reactor

| Término | Definición |
| :--- | :--- |
| **Lote (batch)** | Una carga completa de flor + solvente procesada de principio a fin. Es la unidad de registro. |
| **Maceración** | Contacto de la flor con el etanol durante un tiempo definido para disolver los compuestos de interés. |
| **Hop spider / cesta** | Canasto de malla inox que contiene la flor dentro del estanque y se retira en una pieza. |
| **Overhead stirrer / agitador** | Motor sobre el estanque que hace girar un eje con hélice sumergida. |
| **Zona de vapores** | Volumen alrededor y por debajo del borde del estanque donde se puede acumular vapor de etanol. Ahí no debe haber equipos eléctricos. |
| **Punto de inflamación** | Temperatura mínima a la que el vapor de un líquido se enciende con una fuente de ignición. Etanol 96°: ≈13–17 °C. |
| **Winterización** | Enfriar el extracto en etanol para precipitar ceras y lípidos, y luego filtrar. |
| **Recuperación de solvente** | Evaporar y condensar el etanol para separarlo del extracto. Es la etapa de mayor riesgo de incendio. |
| **Mark (MK)** | Iteración del prototipo que responde una pregunta central (MKI, MKII, MKIII). |
